# Security policy

This repository is a research prototype and has no supported releases. If you find a
vulnerability in the code, please report it privately through the "Report a vulnerability"
button on the Security tab of the GitHub repository and do not open a public issue. Include the
affected file, the steps to reproduce and the effect you observed. The repository holds no
credentials, and the live world talks only to the test mode of its provider, so a finding
should not involve real funds or real accounts.
